Prompt 1: Establish the Project Concept
I am developing an Edge AI-based classroom attendance system called EdgeClass. Help me build the application incrementally, using local processing wherever possible. The goal is to automate classroom attendance and monitor student attention using a live camera feed.
First, review the existing project structure and code before making changes. Build on the current implementation instead of unnecessarily rewriting the application from scratch.
Prompt 2: Implement Live Facial Recognition
Integrate real-time facial detection and recognition into the classroom camera interface.
Requirements:
* Use the existing student database containing student names and photographs.
* Detect students appearing in the live camera feed.
* Display a green bounding box around each recognized student.
* Show the recognized student's name on or near the bounding box.
* Match detected faces against the existing student database.
* Process the camera feed locally in the browser wherever possible.
Ensure that the implementation uses the existing project dependencies and model files where appropriate.
Prompt 3: Automate Attendance Tracking
Implement an attendance system that automatically records student presence during a classroom session.
Requirements:
* Mark a student as Present when their face is recognized during the session.
* Mark students who have not been detected as Absent when the attendance report is generated.
* Associate attendance records with the relevant student IDs and names.
* Prevent repeated detections of the same student from creating duplicate attendance entries.
* Ensure the attendance status is reflected correctly in the user interface.
Investigate and fix any issues that prevent recognized students from being marked present.
Prompt 4: Detect Student Head Direction
Extend the facial recognition system to estimate whether each student is facing the front of the classroom.
Requirements:
* Estimate the direction of each detected student's head.
* Identify students who appear to be looking away from the front.
* Track the accumulated time each student spends facing away from the front during the session.
* Display the relevant status in the interface.
* Associate the observations with the correct recognized student.
Treat head direction as an estimate based on visual information, rather than claiming to measure a student's actual attention or understanding.
Prompt 5: Improve Recognition Accuracy and Reliability
Review the existing facial recognition implementation and improve its reliability.
Requirements:

Prompt 6: Keep Processing Local and Minimize External Dependencies
